# Bulimia

Long-flow control for AI.

Most AI models forget things over long flows because of poor memory, or hallucinate and reveal future secrets too early. Bulimia adds long-flow control: during each stage, the information the AI can access is restricted.

Getting started: install Node.js and double-click `Start.bat`; on other systems, run `npm install` and `npm start` in the `server` directory, then open http://localhost:36426 .

API keys are stored only in your local browser.

How to write a module: see [docs/en/CREATING_MODULES.md](docs/en/CREATING_MODULES.md).
