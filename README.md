# Bulimia

AI 长流程控制。

因为大部分的 ai 限制于长流程的记忆差导致遗忘，或者幻觉提前解开未来的秘密。因此设置了长流程控制，每段时间中 ai 都被限制获取的信息内容。

启动：安装 Node.js 后双击 `Start.bat`；其他系统在 `server` 目录运行 `npm install` 和 `npm start`，再打开 http://localhost:36426 。

API 密钥只保存在本机浏览器里。

怎么写模组：见 [docs/CREATING_MODULES.md](docs/CREATING_MODULES.md)。
